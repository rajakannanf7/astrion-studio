# Astrion Studio

Website for Astrion Studio — a studio space for hire in **Surandai, Tenkasi District,
Tamil Nadu**.

Three rooms, one floor:

| Room | Size | Used for |
|---|---|---|
| Studio A — Cyclorama | 1,600 sq ft | Stills, video, product, personal branding |
| Podcast Room One | 400 sq ft | Host + guest, solo and interview |
| Podcast Room Two | 400 sq ft | Four-seat panel and roundtable |

Sold three ways: the room by the hour, personal-branding shoots, and podcast production.

Static HTML + Tailwind CSS v4. No framework, no runtime build — the only build step
compiles the stylesheet.

## Quick start

```bash
npm install
npm run dev     # rebuild styles.css on change
```

Then open `index.html`, or serve the folder:

```bash
npm run serve   # http://localhost:3000
```

In Claude Code, `preview_start` with the `astrion` config in `.claude/launch.json`
serves the same thing on port 3000.

## Scripts

| Script | What it does |
|---|---|
| `npm run build` | Compile + minify `assets/css/tailwind.css` → `assets/css/styles.css` |
| `npm run dev` | Same, in watch mode |
| `npm run serve` | Static file server on port 3000 |

**`assets/css/styles.css` is generated — never edit it by hand.** Edit
`tailwind.css` (tokens, base, buttons/cards/inputs) or `components.css`
(everything specific to this site), then rebuild.

## Design system

Generated by the `ui-ux-pro-max` skill and recorded in
`design-system/astrion-studio/MASTER.md`.

- **Style:** Motion-Driven · **Pattern:** Scroll-Triggered Storytelling
- **Colour:** pure black `#000000` ground, `#FAFAFA` foreground, near-white accent
- **Type:** Archivo (display) / Space Grotesk (body)

Tokens live in the `@theme` block of `tailwind.css`. Note the spacing scale is
deliberately named `--space-*`, not `--spacing-*`: the latter would hijack
Tailwind's own named scales and break `max-w-md`, `max-w-xs` and friends.

## Brand

The logo is reproduced in markup, not as an image file:

- **The angular "A"** is an inline SVG path (`.logo-mark`) — it is a custom mark,
  not a font glyph. It inherits `--color-brand`, so it recolours with the theme.
- **"STRION" / "STUDIO"** are set in **Saira 600/500**, subset at request time to
  the nine letters the lockup uses (`&text=ASTRIONUD`) — roughly 2 KB.
- The lockup is a centred column: mark + wordmark on one row, `STUDIO`
  letterspaced and optically centred beneath.

**Brand amber is `#F9A31B`**, sampled from the supplied logo. It is defined once as
`--color-brand` and aliased to `--color-accent`, which replaced the near-white accent
the generated design system started from. That single change carries the brand
through every accent surface: primary buttons, the active filter pill, the scroll
progress bar, focus rings, text selection, the skip link, and the service-icon hover
state. `--color-on-accent` is `#0A0A0A` — amber needs dark text (black on this amber
is about 9:1; white would be about 2.3:1 and would fail).

If you have the original vector, drop it in and replace the `.logo-row` markup —
everything else is already on the brand token.

## Imagery

The four photographs in `assets/img/` are AI-generated: **Seedream 5 Pro** for the base
renders, then **Magnific Precision (ultra-photo, 2x)** to upscale — 5–6K masters
downscaled to web sizes.

| File | Where it appears | Size |
|---|---|---|
| `hero-cyclorama.jpg` | Hero background (2400px, 21:9) | 243 KB |
| `space-cyclorama.jpg` | Studio A tile + tour modal | 122 KB |
| `space-podcast.jpg` | Podcast Room One tile | 161 KB |
| `space-podcast-b.jpg` | Podcast Room Two tile | 127 KB |

**These are stand-ins for photographs of the real rooms.** Swap each for an actual
photo at the same path and nothing else changes — the hero uses `bg-cover bg-center`
and `.work-card` sets `background-size: cover`.

`assets/img/_unused/` holds four images from an earlier draft that depicted rooms this
studio does not have (daylight loft, black box, green room, branding set). They are
parked out of the served set rather than deleted — remove the folder when you are sure.

## Accessibility notes

Built against the design system's pre-delivery checklist:

- Icons are inline SVG, never emoji
- `cursor: pointer` on every clickable element; visible `:focus-visible` rings
- Transitions 150–500ms; `prefers-reduced-motion` disables reveals, the marquee
  and smooth scrolling, and renders every section in its final state
- Skip link, labelled form fields, `aria-live` status on filter and form
- Verified at 375 / 768 / 1024 / 1440px with no horizontal scroll
